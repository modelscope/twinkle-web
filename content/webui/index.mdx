`ms-webui` is the graphical workbench of the SWIFT stack: model chat, training
launch and monitoring, drag-and-drop orchestration, and AutoResearch experiment
automation — all driving the same SWIFT/twinkle underneath.

- [Quick Start](./quick-start.mdx) — install and first launch.
- [Features](./features.mdx) — what each page does.
- [AutoResearch](./autoresearch.mdx) — one instruction, a whole experiment.
- [Orchestration](./orchestration.mdx) — the drag-and-drop training canvas.
- [Tests & Leaderboard](./benchmarks.mdx) — evaluation status.

The WebUI is a local application: it starts a dev server on your machine and
talks to your local SWIFT installation. This documentation site is static and
does not run it.
