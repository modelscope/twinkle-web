title: 编排
description: 拖拽画布组合的正是代码 API 用的同一批组件。
---

Workflow 页是 SWIFT/twinkle 组件面之上的画布：模型、数据集、采样器、
loss、reward、训练步是节点；边在节点间传类型化数据。

让它保持诚实的设计事实：

- **节点就是真实组件。** 画布节点映射到 Python API 用的同一注册组件——
  不是 UI 专属近似。连出来的就是跑起来的。
- **UI 里只放轻胶水，控制流在组件里。** 画布上的代码块承载小适配器；
  算法逻辑留在注册组件。
- **类型化端口。** 连线按数据类型校验，非法接线在编辑期被拒，
  而不是 run 到一半才炸。
- **预设。** 常见 recipe（SFT、GRPO、embedding 训练）以起始画布提供，
  改而不是从零画。

画布产出的配置与表单/脚本产出的相同；可导出等价命令无头运行。
